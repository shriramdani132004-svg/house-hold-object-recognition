# Phase 3 — Data Preparation Completion Report

**Status: COMPLETE — validation PASS, 58 tests passed.**

All numbers below were measured from the generated files; no estimates.

## What was done

1. Analyzed all 80 COCO categories (`scripts/analyze_categories.py` →
   `reports/phase3_category_analysis.md`).
2. Selected 19 household classes against documented frequency thresholds
   (`reports/phase3_class_selection.md`, config: `configs/dataset.yaml`).
3. Converted COCO instances JSON to YOLO bbox labels, copied selected
   images, and created deterministic splits
   (`scripts/prepare_dataset.py` → `data/processed/household_objects/`).
4. Validated the prepared dataset (`scripts/validate_prepared_dataset.py`
   → `reports/phase3_dataset_validation.md`).
5. Rendered sample visualizations and statistics
   (`reports/phase3_samples/`, `reports/phase3_dataset_statistics.md`,
   `reports/figures/phase3_*.png`).

## Splits

- COCO train2017 → project train (90%) + val (10%), seed 42
  (`split_seed: 42`, `val_fraction: 0.1`).
- COCO val2017 → project test (no overlap; filenames unique across
  splits).
- `iscrowd` annotations excluded; min box size 1.0 px; segmentation
  polygons dropped (bbox-only YOLO format).

## Reproducibility

Run from the project root with the project virtual environment:

```bash
.\.venv\Scripts\python.exe scripts/analyze_categories.py
.\.venv\Scripts\python.exe scripts/prepare_dataset.py
.\.venv\Scripts\python.exe scripts/validate_prepared_dataset.py
.\.venv\Scripts\python.exe scripts/visualize_prepared_dataset.py
.\.venv\Scripts\python.exe scripts/dataset_statistics.py
```

`prepare_dataset.py` rebuilds the output directory from scratch, so the
pipeline is idempotent. Raw COCO data under `data/raw/coco/` is only read,
never written.

## Known limitations

- The processed dataset (7.2 GB) and sample visualizations are
  git-ignored; they are regenerated by the commands above.
- Class imbalance is inherent to COCO (16.8x max/min); no resampling or
  augmentation was applied in this phase.
- Only bbox annotations are used; COCO segmentation masks and captions are
  dropped.
- One content-duplicate image was removed by SHA1 hash; the kept copy
  favors the test split, then val, then train.
