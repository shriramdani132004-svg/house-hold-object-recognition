# Phase 2 sample images

16 PNG frames copied (never moved) from the CORe50 dataset for quick human
inspection of the acquired data.

## Selection method (deterministic)

Generated by `scripts/validate_core50.py → write_samples()`:

- image index `i` (0…15) → session `SESSION_IDS[i % 11]`, i.e. sessions
  s1…s11 are all covered (s1…s5 appear twice);
- category `i % 10` → one of the 10 official CORe50 categories, so all 10
  categories appear; the first 10 picks use object instance 1 of each
  category, picks 11–16 use instance 2;
- within each `(session, object)` directory the **middle frame of the sorted
  frame list** is copied, so the choice is reproducible.

Result: 16 files, 11 sessions, 16 distinct object identities, 10 categories,
both train sessions and the s3/s7/s10 test sessions represented. Filenames
are `sN_oM_<original frame name>.png` (original names preserved).

The originals under `data/raw/core50/dataset/` are never modified.
Selection metadata for every file is stored in
`reports/phase2_core50_summary.json → samples`.
