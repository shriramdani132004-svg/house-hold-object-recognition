HOUSEHOLD OBJECT RECOGNITION — COMPLETE PROJECT ROADMAP
========================================================

PHASE 1 — PROJECT SETUP
Create project structure, Python environment, Git, configuration,
basic README, and AGENTS.md.

PHASE 2 — DATASET
Select a suitable public household-object detection dataset,
download/acquire it, and document the dataset and license.

PHASE 3 — DATA PREPARATION
Clean the dataset, select final household-object classes,
convert annotations if needed, create train/validation/test splits,
and validate the prepared dataset.

PHASE 4 — DATASET ANALYSIS
Generate class distribution, sample annotated images,
object-size statistics, annotation visualizations,
and identify dataset quality or imbalance problems.

PHASE 5 — BASELINE MODEL
Load a pretrained lightweight YOLO model and test it on sample
images before custom training.

PHASE 6 — MODEL TRAINING
Train the custom household-object detection model and save
checkpoints, logs, training curves, and metrics.

PHASE 7 — MODEL EVALUATION
Evaluate the trained model on validation/test data using:
precision, recall, mAP50, mAP50-95, confusion matrix,
per-class metrics, and inference speed.

PHASE 8 — ERROR ANALYSIS & IMPROVEMENT
Find missed objects, false positives, wrong classifications,
poor bounding boxes, small-object failures, occlusion problems,
and other real-world errors. Improve the dataset or training
configuration based on the observed failures.

PHASE 9 — FINAL MODEL
Run the improved training experiment, compare experiments,
select the final model based on actual test performance,
model size, and inference speed, and freeze/document the
final model version.

PHASE 10 — INFERENCE SYSTEM
Build clean reusable Python inference code for:
- image prediction
- bounding boxes
- class names
- confidence scores
- object counts
- inference time
- configurable confidence threshold

Support reusable inference for both static images
and camera/video frames.

PHASE 11 — WEB APP + LIVE CAMERA
Build a professional Gradio application with:

1. IMAGE UPLOAD MODE

- annotated image
- detected object names
- confidence scores
- bounding boxes
- object count
- inference time

2. PC/LAPTOP WEBCAM MODE
Allow the user to access the computer's webcam and perform
live household-object detection.

3. PHONE LIVE CAMERA MODE
Design the web application so it can be opened from a phone
browser and use the phone's camera for live detection.

- camera permission handling

- confidence threshold
- detection count
- inference time/FPS where practical
- clear error messages
- mobile-friendly UI
- example images
- image upload fallback
