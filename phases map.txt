| 19 | Continual Recognition of Household Objects | Develop an object-recognition system that learns household objects over multiple sessions and changing environments while minimizing forgetting of previously learned objects. | CORe50 | https://vlomonaco.github.io/core50/ | Continual Object Recognition |

=====================================================================
PROJECT GOAL
=====================================================================

Build a continual household-object recognition system using CORe50.

The final system must demonstrate:

1. Household objects learned incrementally across sessions/experiences.
2. New object instances and/or classes introduced over time.
3. Previously learned knowledge evaluated after new learning.
4. Forgetting measured.
5. Naive continual learning compared with ONE anti-forgetting method.
6. Experience Replay used as the anti-forgetting method.
7. A final model capable of inference.
8. A simple public web application.
9. Phone browser access.
10. Phone camera live recognition.
11. Object name and confidence displayed.
12. Bounding boxes where supported by the selected model.

=====================================================================
PHASE 4 — NAIVE CONTINUAL LEARNING + EXPERIENCE REPLAY
=====================================================================

STATUS: ✅ COMPLETE

PRIMARY OBJECTIVE:

Implement the two continual-learning approaches required by the project.

METHOD A — NAIVE CONTINUAL LEARNING

- Sequential training
- No replay
- Persistent model state
- No model reset between experiences

METHOD B — EXPERIENCE REPLAY

- Bounded replay memory
- Current experience + previous samples
- Replay memory contains training references only
- Persistent replay state
- Deterministic replay sampling
- No future samples
- No evaluation samples

Shared requirements:

- Same model architecture
- Configurable training
- Persistent checkpoints
- Resume support
- Reusable trainer interface
- No random dataset split
- No additional anti-forgetting algorithms

Only ONE anti-forgetting strategy:

EXPERIENCE REPLAY

Do NOT implement:

- EWC
- LwF
- knowledge distillation
- multiple replay methods
- hyperparameter search
- architecture search
