HOUSEHOLD OBJECT RECOGNITION — UPDATED MASTER ROADMAP
======================================================

CORE ASSIGNMENT
===============

Continual Recognition of Household Objects

Develop a continual object-recognition system that learns household objects
over multiple sessions and changing environments while minimizing forgetting
of previously learned objects.

PRIMARY DATASET:
CORe50

PRIMARY RESEARCH GOAL:
Build a continual-learning model that can correctly recognize the learned
CORe50 household-object identities from uploaded images and camera images,
while minimizing forgetting of previously learned objects.

IMPORTANT SCOPE:

The practical recognition target is the 50 CORe50 object identities.

The system must NOT claim to recognize arbitrary household objects outside
the CORe50 label space.

For an image belonging to a CORe50 class:
    image → preprocessing → final continual model → object identity + confidence

For a non-CORe50 object:
    the system should not falsely imply that it belongs to the CORe50 set.
    Where practical, unknown/out-of-scope handling may be added.

PHASE E — UNKNOWN / OUT-OF-SCOPE HANDLING
-----------------------------------------

OBJECTIVE:

Prevent the application from misleading users when an image is outside
the 50-class CORe50 label space.

The base model is a closed-set classifier.

Therefore implement an "unknown / unsupported object" mechanism ONLY if it
can be justified and evaluated properly.

Possible approaches:

- calibrated confidence threshold
- rejection threshold
- out-of-distribution smoke testing
- explicit "Not confidently recognized" state

Do NOT simply use an arbitrary threshold and call it scientifically valid.

Evaluate false rejection and false acceptance behavior.

The app must clearly distinguish:

KNOWN CORe50 OBJECT
versus
UNSUPPORTED / UNCERTAIN INPUT
